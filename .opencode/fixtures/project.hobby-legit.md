## Elevator Pitch
A local-only notebook for logging hikes, so I can remember which trails I liked.

## Problem
I forget which trails I've done and what the conditions were. Existing apps want
an account and upload my location history to someone else's server.

## Solution
A single-user app that runs on my laptop and writes plain markdown files to a
folder I already back up. No account, no server, no sync.

## Target Audience
**Primary user:** me. There is no second user and there is not intended to be one.

## Scope

### MVP — In Scope
- Log a hike: date, trail, distance, notes
- Browse past entries
- Full-text search

### Never Building
- Any hosted or multi-user version
- Social features of any kind
- A mobile app

## Revenue Model
None. This is not a product. The commercial alternatives cost around $30/year;
that is the reason I am building my own rather than a market I am entering.

## Success Definition
I use it after three hikes in a row without it annoying me.
