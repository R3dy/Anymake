# [Project Name] — Established Conventions

**Purpose:** The running record of patterns already established in this codebase, so the Planner can brief new stories against what exists instead of re-deriving it from scratch each time, and the Worker can build consistently with prior stories.

**Maintenance rule:** The Worker appends an entry here after a story establishes a pattern that doesn't already have one — a new pattern, not a restatement of an existing entry. Append only; never delete or rewrite another story's entry (if a later story deliberately supersedes a pattern, add a new entry and mark the old one "Superseded by Story N.N," the same append-only discipline `DECISIONS.md` uses). This file is read, not curated — keep entries short and pointer-based, not prose.

**Entry format:**
```
### [Category] — [pattern name]
**Established by:** Story N.N
**Pattern:** [one or two sentences]
**See:** `[file path]` — [what to look at]
```
